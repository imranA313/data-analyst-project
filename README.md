## 📌 Overview

This project demonstrates the end-to-end data analysis workflow:
1. **Data Collection** – Loading raw datasets
2. **Data Cleaning** – Handling missing values, duplicates, and outliers
3. **Exploratory Data Analysis (EDA)** – Understanding patterns and distributions
4. **Data Visualization** – Charts and graphs for storytelling
5. **Insights & Conclusions** – Business-ready findings

## 🛠️ Tech Stack

| Pandas | Data manipulation |
| NumPy | Numerical computing |
| Matplotlib | Basic visualizations |

## ⚙️ Installation

```bash

git clone https://github.com/imranA313/data-analyst-project.git

# 2. Navigate to the project folder
cd data-analyst-project

# 3. Install dependencies
pip install -r requirements.txt
```

## 🚀 Usage

```bash
# Run Jupyter Notebook
jupyter notebook notebooks/analysis.ipynb
```

Or run individual scripts:

```bash
python src/data_cleaning.py
python src/eda.py
```
